# Practice Relay glossary

| Term | Meaning |
|---|---|
| Practice Relay | WorkRecord handoff application |
| WorkRecord | Portable record that groups selected work versions, evidence, roles, use conditions, and export provenance for a handoff |
| work-record package | Practice Relay package profile using RO-Crate as its packaging substrate |
| Preferred take | Selected take used as the reference for a handoff or export |
| movement_annotation | Structured movement notes, not symbolic MvEI data |
| MvEI | Movement Encoding Initiative, a separate movement-encoding effort |
| MvEI Workbench | Separate authoring UI that round-trips MvEI data |
| Q-gate | Testable product-boundary or acceptance condition |
