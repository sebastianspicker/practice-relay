# MvEI glossary

| Term | Meaning |
|---|---|
| MvEI | Movement Encoding Initiative, a movement-encoding effort |
| MvEI Workbench | Separate authoring application that loads, edits, and emits MvEI data |
| Practice Relay | Separate WorkRecord handoff application that can reference MvEI packages |
| Motif | Simplified symbolic movement-encoding profile |
| movement_annotation | Practice Relay structured notes, distinct from symbolic MvEI data |
| LabanLite | A separate computer-vision research representation, not MvEI |
| Dual strategy | Link symbolic encoding with annotation, video, and capture practices rather than treating notation as a replacement |
