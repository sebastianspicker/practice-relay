Boundaries

Neighbours are not MvEI

Neighbours (not MvEI)

  • LabanLab: Research web UI + motion preview: not MvEI
  • LaMoGen / LabanLite: CV motion-gen IR: not ICKL-grade encoding standard
  • MARC 358: Cataloguing notated movement: metadata ally, not score-file stack
  • LabanWriter: Legacy Mac free graphical editor
  • KineScribe: Free Motif/Laban literacy app
