# @practice-relay/work-record-core

Portable WorkRecord Core v0.4 contracts and pure domain behavior. The package
combines record membership, time spine, tracks, takes, critique, immutable
versions and snapshots, explicit use policy, MvEI co-timeline integration,
RO-Crate 1.3 package IO, and a revision-aware in-memory store.

Supported neutral profile IDs are `urn:work-record:profile:core:0.4`,
`urn:work-record:profile:design-studio:0.1`, and
`urn:work-record:profile:field-study:0.1`.
