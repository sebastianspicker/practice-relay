# Pilot evaluation - interpretation rule

Do not score participants or grade their work through this instrument. Review the [baseline/pilot measures](baseline-pilot-measures.md) with the following questions:

1. Did the pilot preserve a resolvable version, selected evidence, accountable roles, and relevant policy conditions?
2. Did it reduce documented reconstruction work or review/deposit delay for the same work type?
3. Which source systems correctly remained authoritative?
4. Did any benefit require Practice Relay to become a generic LMS, ePortfolio, DAM, repository, video editor, or authoring suite?
5. Did a security, privacy, accessibility, repository, or policy concern outweigh the benefit?

Record facts, denominators, exceptions, and contrary evidence in the decision
log. Stop or narrow the study if an incumbent already preserves the handoff,
policy owners reject the package, or the required change would turn Practice
Relay into a generic authoring, assessment, portfolio, media, or repository
system. Never present a pilot as automated grading, institutional validation,
or replacement proof.
