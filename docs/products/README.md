# Product boundaries

This directory defines the names and separation rules used by the source, tests,
and public documentation.

- [`naming.md`](naming.md) defines the four maintained names.
- [`../ARCHITECTURE.md`](../ARCHITECTURE.md) covers shared contracts, application
  ownership, dependency direction, and runtime flows.
- [`merge-decision.md`](merge-decision.md) records why Practice Relay and MvEI
  Workbench stay separate applications.

Implementation details belong in the [Practice Relay documentation](../relay/README.md),
the [MvEI documentation](../movement/README.md), and
[`../../packages/README.md`](../../packages/README.md).
